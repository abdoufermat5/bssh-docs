## Agentes de IA que preguntan antes de actuar

bssh AI conecta Claude Code, Codex, Cursor y otros agentes a tus hosts mediante un servidor MCP local. El agente nunca tiene una clave ni abre un shell. Las lecturas se ejecutan al instante, en un entorno aislado de solo lectura. Todo lo que cambia un host te espera y se ejecuta exactamente como lo aprobaste.

```text frame="terminal"
$ bssh ai install claude-code
$ bssh ai explain --host web-1 "journalctl -u nginx -n 50" | tail -1
decision: allow - analyzer: every command is read-only
$ bssh ai explain --host web-1 "systemctl reload nginx" | tail -1
decision: deny - profile.observe: the observe profile cannot change anything
```

De entrada, los agentes solo pueden leer. Una entrada de política les permite proponer cambios, y tú apruebas cada uno.

## Seguro desde el diseño

Cada uno de estos puntos lo aplica bssh, no depende de buenas prácticas.

<CardGrid>
	<Card title="Tus claves siguen siendo tuyas" icon="padlock">
		bssh usa tus claves y tu agente SSH donde están. Los agentes de IA nunca tienen una clave y ningún intermediario se interpone entre tú y tus servidores.
	</Card>
	<Card title="Decisiones legibles" icon="list-format">
		Un analizador de shell y tu política deciden qué puede ejecutar un agente. Ningún modelo interviene, y `bssh ai explain` muestra el resultado de antemano.
	</Card>
	<Card title="Una persona aprueba los cambios" icon="approve-check">
		Los cambios esperan una aprobación, con el comando y el diff exactos. Con la autoridad de certificación local, un comando aprobado se ejecuta con un certificado válido solo para él.
	</Card>
	<Card title="Un registro verificable" icon="document">
		Las llamadas de los agentes y las sesiones del equipo van a registros firmados y encadenados que puedes verificar en tu propia máquina.
	</Card>
	<Card title="Uso compartido cifrado de extremo a extremo" icon="link-alt">
		bssh Teams cifra las conexiones compartidas en tus dispositivos. El servidor de sincronización nunca ve hosts, usuarios ni claves.
	</Card>
	<Card title="Versiones firmadas" icon="approve-check-circle">
		Cada versión está firmada e incluye la procedencia de su compilación. El instalador verifica las sumas de comprobación, y la firma cuando cosign está instalado.
	</Card>
</CardGrid>
