Bayesian SSH provides a keyboard-driven desktop application alongside the command-line tool. Both use the same local SQLite database, configuration, and environment profiles.

## Launching the application

Launch the desktop interface from your application menu, or run it from a terminal:

```sh
bssh desktop
```

The command starts `bayesian-ssh-desktop` in the background, detached from your terminal session. You can also run the binary directly:

```sh
bayesian-ssh-desktop
```

To start the desktop application with a specific environment profile, pass the `--env` flag:

```sh
bssh desktop --env staging
```

## Interface layout

The sidebar organizes your workflow into dedicated views:

![The desktop app host list showing saved connections, tags, and quick actions](../../../assets/screenshots/app-hosts.png)

- **Hosts**: View, filter, and search saved connections. See rankings, connection status, tags, and quick actions.
- **Terminals**: A built-in multi-tab terminal emulator. Connect to multiple hosts simultaneously, switch or reorder tabs, and search terminal output.
- **Files**: An SFTP file manager for browsing remote directories, uploading, and downloading files. You can toggle this view in Settings.
- **Keys**: Inspect local SSH keys, generate new keypairs, and view keys currently active in your SSH agent.
- **Security check**: Run security audits directly from the interface (`bssh audit`) to identify weak algorithms, missing keys, or insecure permissions.
- **History**: Review past connection sessions and usage timestamps.
- **Teams**: Manage team connections, member invitations, device approvals, and verified audit logs.
- **Settings**: Adjust application preferences, appearance, terminal fonts, updates, and environment profiles.

<Aside type="note">
Local port forwarding and SOCKS proxies are managed on the command line using `bssh forward` (or `bssh tunnel`). See the [Tunnels guide](/guides/tunnels/) for port-forwarding options.
</Aside>

## Command palette and keyboard shortcuts

Open the command palette from anywhere by pressing <kbd>Ctrl</kbd>+<kbd>K</kbd> (or <kbd>⌘</kbd><kbd>K</kbd> on macOS).

Inside an active terminal tab on Linux or Windows, press <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> (<kbd>⌘</kbd><kbd>K</kbd> on macOS) to open the palette without intercepting shell control chords.

![Command palette searching actions and host verbs](../../../assets/screenshots/app-palette.png)

The command palette allows you to search hosts, switch views, edit connections, browse files, and run commands. Press <kbd>?</kbd>, <kbd>F1</kbd>, or <kbd>Ctrl</kbd>+<kbd>/</kbd> (<kbd>⌘</kbd><kbd>/</kbd> on macOS) to open the full keyboard shortcut sheet.

## Themes and density

Configure appearance preferences under **Settings** → **Appearance**:

![Appearance settings showing theme and density options](../../../assets/screenshots/app-settings-appearance.png)

### Themes

- **Dark**: High-contrast dark theme designed for low-light environments.
- **Light**: Clean, light color scheme.
- **Match system**: Automatically switches between dark and light themes based on your desktop operating system settings.

### Row density

Density controls the vertical spacing of list rows throughout the application:

- **Compact**: 32 px rows. Maximizes visible items for large host lists.
- **Comfortable**: 40 px rows. Balanced spacing for everyday use (default).
- **Spacious**: 48 px rows. Relaxed spacing suited for touch screens and high-resolution displays.

## Software updates

Open **Settings** → **Updates** to inspect your current version and check for software updates. The update mechanism reflects your installation method:

- **Snap package**: Updates are handled automatically in the background by the Snap Store. You can update manually using:
  ```sh
  sudo snap refresh bayesian-ssh
  ```
- **Manual installation**: If installed via `install.sh` or your operating system package manager, update by re-running the installation script or through your package manager.
- **Direct GitHub release**: Click **Check for updates** to query GitHub for newer signed releases. When an update is available, click **Install update** to download and apply it. The application prompts for confirmation if active terminal sessions are running.
