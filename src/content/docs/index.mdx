```sh frame="terminal"
bssh add web-prod web-prod.example.com --tags prod,web
bssh connect prod
```

	<Card title="Finds the host you mean" icon="magnifier">

	</Card>
	<Card title="Bastions and Kerberos built in" icon="server">
		Jump hosts, interactive bastions and Kerberos tickets are handled for you, per connection or by default.
	</Card>
	<Card title="Command line and desktop" icon="laptop">
		The same hosts in `bssh` and in the desktop app, with terminals, file transfer and session history.
	</Card>
	<Card title="Shared with your team" icon="padlock">
		bssh Teams syncs connections through a vault encrypted on your devices, with a signed audit log.
	</Card>
