## AI agents that ask before they act

bssh AI connects Claude Code, Codex, Cursor and other agents to your hosts through a local MCP server. The agent never holds a key or opens a shell. Reads run straight away, in a read-only jail. Anything that changes a host waits for you, and runs exactly as approved.

```text frame="terminal"
$ bssh ai install claude-code
$ bssh ai explain --host web-1 "journalctl -u nginx -n 50" | tail -1
decision: allow - analyzer: every command is read-only
$ bssh ai explain --host web-1 "systemctl reload nginx" | tail -1
decision: deny - profile.observe: the observe profile cannot change anything
```

Out of the box, agents can only read. One policy entry lets them propose changes, and you approve each one.

## Secure by design

Each of these is enforced by bssh itself, not left to good practice.

<CardGrid>
	<Card title="Your keys stay yours" icon="padlock">
		bssh uses your SSH keys and agent where they are. AI agents never hold a key, and no relay sits between you and your servers.
	</Card>
	<Card title="Decisions you can read" icon="list-format">
		A shell parser and your policy decide what an agent may run. No model takes part, and `bssh ai explain` shows the outcome in advance.
	</Card>
	<Card title="A person approves changes" icon="approve-check">
		Changes wait for approval, with the exact command and diff. With the local CA, an approved command runs with a certificate valid for that command only.
	</Card>
	<Card title="A record you can verify" icon="document">
		Agent calls and team sessions go to signed, hash-chained logs, which you can check on your own machine.
	</Card>
	<Card title="End-to-end encrypted sharing" icon="link-alt">
		bssh Teams encrypts shared connections on your devices. The sync server never sees hosts, users or keys.
	</Card>
	<Card title="Signed releases" icon="approve-check-circle">
		Every release is signed and carries build provenance. The installer verifies the checksums, and the signature when cosign is installed.
	</Card>
</CardGrid>

## Everyday SSH, one keystroke away

<DemoVideo label="Demo: importing hosts from ~/.ssh/config, a fuzzy connect, a connection through a bastion, one command and one upload on several servers at once, the session history, then the desktop app with two live terminals and the command palette." />

```sh frame="terminal"
curl -fsSL https://bssh.abdoufermat.dev/install.sh | bash
bssh add web-prod web-prod.example.com --tags prod,web
bssh connect prod
```
