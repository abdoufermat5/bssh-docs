This page lists every `bssh` command, the options it accepts and the values it takes. Commands are grouped by what they do.

## Global options

```text
Usage: bssh [OPTIONS] [COMMAND]
```

| Flag | Description |
| --- | --- |
| `--env <ENV_NAME>` | Override the active environment for this invocation (does not persist). |
| `-h, --help` | Print help. After a command, print the help for that command. |
| `-V, --version` | Print version. |

Every command also accepts `--env` and `-h, --help`. Add `-h` after any command to see its own help, for example `bssh connect -h`. `bssh help <COMMAND>` prints the same text.

Five commands have a shorter alias: `bssh gui` for `desktop`, `bssh run` for `exec`, `bssh tunnel` for `forward`, `bssh socks` for `proxy`, and `bssh kill` for `close`.

## Connections

Save, inspect and edit the hosts you connect to, manage the keys they use, and jump to one from the terminal.

### bssh connect

Open an SSH session to a saved connection. The target is matched by name, alias or hostname using fuzzy search, and Bayesian scoring ranks the best match. The flags below override the stored settings for this session.

```text
Usage: bssh connect [OPTIONS] <TARGET>
```

| Flag | Description |
| --- | --- |
| `<TARGET>` | Connection name, alias, or hostname (fuzzy-matched). |
| `-u, --user <USER>` | Override the SSH username for this session. |
| `-p, --port <PORT>` | Override the stored SSH port for this session. |
| `-k, --kerberos <BOOL>` | Force Kerberos auth on or off for this session. Possible values: `true`, `false`. |
| `-b, --bastion <HOST>` | Route through this bastion/jump host. |
| `--no-bastion` | Bypass any configured bastion and connect directly. |
| `-B, --bastion-user <USER>` | Username for the bastion host. |
| `-i, --key <FILE>` | Path to an SSH private key to use. |
| `--record` | Record this session's output (overrides config). |
| `--no-record` | Do not record this session's output (overrides config). |

### bssh add

Save a new named connection to the database. The name is the identifier you pass to `connect`, `exec`, `upload` and the other commands.

```text
Usage: bssh add [OPTIONS] <NAME> <HOST>
```

| Flag | Description |
| --- | --- |
| `<NAME>` | Friendly name for this connection (must be unique). |
| `<HOST>` | Server hostname or IP address. |
| `-u, --user <USER>` | SSH username (falls back to config default or `$USER`). |
| `-p, --port <PORT>` | SSH port (default: the configured default port, usually 22). |
| `-k, --kerberos <BOOL>` | Enable Kerberos (GSSAPI) authentication. Possible values: `true`, `false`. |
| `-b, --bastion <HOST>` | Bastion/jump host to route through. |
| `--no-bastion` | Mark as direct connection (ignore default bastion). |
| `-B, --bastion-user <USER>` | Username for the bastion host. |
| `-i, --key <FILE>` | Path to an SSH private key. |
| `-t, --tags <TAG>` | Tags for grouping and filtering (repeatable or comma-separated). |

| `-d, --detailed` | Show full connection details (host, port, bastion, auth). |

### bssh edit


| `--port <PORT>` | Change the SSH port. |

| `--bastion <HOST>` | Set or change the bastion host. |
| `--no-bastion` | Remove the bastion (switch to direct connection). |
| `--bastion-user <USER>` | Change the bastion username. |
| `--key <FILE>` | Set or change the SSH private key path. |
| `--add-tags <TAG>` | Add tags (repeatable or comma-separated). |
| `--remove-tags <TAG>` | Remove tags (repeatable or comma-separated). |

## Search and sessions

Find the right host, understand its rank, and review what you did.

### bssh why

Break down the Bayesian ranking score of a saved connection factor by factor: frequency prior, recency, success rate, and context likelihood ratios (repository, hour of day, and previous connection).

```text
Usage: bssh why [OPTIONS] <TARGET>
```

| Flag | Description |
| --- | --- |
| `<TARGET>` | Connection name, alias, or ID. |

### bssh stats

Show usage statistics: total connections, sessions, and top hosts.

```text
Usage: bssh stats [OPTIONS]
```

Takes no options beyond the global ones.

### bssh history

Display a log of past SSH sessions with connection name, start time, duration and exit status.

```text
Usage: bssh history [OPTIONS]
```

| Flag | Description |
| --- | --- |
| `-c, --connection <NAME>` | Show only sessions for this connection name. |
| `-n, --limit <COUNT>` | Maximum number of entries to display (default: 20). |
| `-D, --days <DAYS>` | Limit to sessions from the last N days. |
| `-f, --failed` | Show only sessions that exited with an error. |
| `-g, --grep <TEXT>` | Search recorded session output for a text phrase. |

### bssh replay

Play back a recorded asciicast v2 session in the terminal. Find session IDs with `bssh history` or `bssh history --grep <text>`.

```text
Usage: bssh replay [OPTIONS] <SESSION>
```

| Flag | Description |
| --- | --- |
| `<SESSION>` | Session ID or unique prefix (at least 6 characters). |
| `-s, --speed <FACTOR>` | Playback speed multiplier (default: 1). |
| `--idle-cap <SECONDS>` | Cap idle pauses to at most this many seconds (default: 2). |

### bssh close

Terminate running SSH sessions started by `bssh`. With no arguments, lists currently active sessions.

```text
Usage: bssh close [OPTIONS] [TARGET]
```

| Flag | Description |
| --- | --- |
| `[TARGET]` | Connection name to close (omit to list active sessions). |
| `-a, --all` | Close all active sessions at once. |
| `--cleanup` | Remove stale session entries (PIDs that are no longer running). |
| `-f, --force` | Skip confirmation prompts. |

## Remote and transfer

Run commands and move files without opening an interactive shell.

### bssh exec

Execute a one-off command over SSH. Supports a single host, all hosts, or a tag. Use `--` to separate the remote command from `bssh` flags.

```text
Usage: bssh exec [OPTIONS] [TARGET] -- <COMMAND>...
```

| Flag | Description |
| --- | --- |
| `[TARGET]` | Connection name, alias, or hostname. |
| `<COMMAND>...` | Remote command and arguments (put `--` before the command). |
| `-a, --all` | Run command on all saved connections in parallel. |
| `-t, --tag <TAG>` | Run command on connections matching this tag. |
| `--dry-run` | Preview target hosts and command without executing. |

### bssh upload

Transfer a local file or directory to one or more hosts, in parallel. Targets are comma-separated names, aliases or hosts, for example `web1,web2,db1`.

```text
Usage: bssh upload [OPTIONS] [TARGETS] <LOCAL> <REMOTE>
```

| Flag | Description |
| --- | --- |
| `[TARGETS]` | Target hosts, comma-separated. |
| `<LOCAL>` | Local file or directory to send. |
| `<REMOTE>` | Destination path on the remote host. |
| `-a, --all` | Upload to all saved connections in parallel. |
| `-t, --tag <TAG>` | Upload to connections matching this tag. |
| `--dry-run` | Preview target hosts and resolved remote paths without connecting. |
| `-j, --parallel <N>` | Maximum number of hosts to upload to concurrently (default: 16). |
| `--offset <BYTES>` | Resume an interrupted upload starting at this byte offset (single host only) (default: 0). |
| `--mode <OCTAL>` | Set file permissions on the remote side (octal, e.g. `0o644`) (default: `0o644`). |
| `-r, --recursive` | Recursively upload an entire directory tree. |

Transfers use SFTP for native connections and fall back to SCP automatically when connecting through an interactive bastion.

### bssh download

Transfer a remote file or directory to the local machine.

```text
Usage: bssh download [OPTIONS] <TARGET> <REMOTE> <LOCAL>
```

| Flag | Description |
| --- | --- |
| `<TARGET>` | Connection name, alias, or hostname. |
| `<REMOTE>` | Path to the file or directory on the remote host. |
| `<LOCAL>` | Local destination path. |
| `-r, --recursive` | Recursively download an entire directory tree. |

## Tunnels

Reach services that are only listening on the remote side.

### bssh forward

Create an SSH local port-forward (`-L` style). Traffic to the local bind address is tunneled to the remote target. The spec is `[bind_addr:]bind_port:remote_host:remote_port`; `bind_addr` defaults to `127.0.0.1` when omitted.

```text
Usage: bssh forward [OPTIONS] -L <SPEC> <TARGET>
```

| Flag | Description |
| --- | --- |
| `<TARGET>` | Connection name, alias, or hostname to tunnel through. |
| `-L <SPEC>` | Forward spec: `[bind_addr:]bind_port:remote_host:remote_port`. |

### bssh proxy

Open an SSH dynamic port-forward (`-D` style) acting as a local SOCKS5 proxy. Point your browser or application to the local port to route traffic through the remote host.

```text
Usage: bssh proxy [OPTIONS] -D <PORT> <TARGET>
```

| Flag | Description |
| --- | --- |
| `<TARGET>` | Connection name, alias, or hostname to proxy through. |
| `-D <PORT>` | Local port for the SOCKS5 listener. |
| `--bind <ADDR>` | Bind address for the SOCKS5 listener (default: `127.0.0.1`). |

## Import and backup

Bring hosts in from other tools, and keep a copy of the database.

### bssh import

Parse an OpenSSH config file or encrypted JSON backup and import each host as a connection. Defaults to `~/.ssh/config` when `--file` is omitted.

```text
Usage: bssh import [OPTIONS]
```

| Flag | Description |
| --- | --- |
| `-f, --file <FILE>` | Path to the SSH config file or backup file (default: `~/.ssh/config`). |
| `--no-bastion` | Import all hosts as direct connections: they never use the default bastion. |
| `-p, --passphrase <PASSPHRASE>` | Passphrase to decrypt encrypted backup file. |

### bssh export

Serialize saved connections to JSON, TOML, or OpenSSH config format. Writes to stdout by default; use `-o` to write to a file.

```text
Usage: bssh export [OPTIONS]
```

| Flag | Description |
| --- | --- |
| `--format <FMT>` | Output format: `json`, `toml`, or `ssh-config` (default: `json`). |
| `-o, --output <FILE>` | Write output to this file instead of stdout. |
| `-t, --tag <TAG>` | Export only connections matching this tag. |
| `-p, --passphrase <PASSPHRASE>` | Encrypt export payload with a secret passphrase. Requires `--output`. |

### bssh backup

Back up the connection database to a file.

```text
Usage: bssh backup [OPTIONS]
```

| Flag | Description |
| --- | --- |
| `-o, --output <FILE>` | Destination path (default: `ENV_DIR/backups/backup-TIMESTAMP.db`); must not already exist. |

### bssh restore

Restore the connection database from a previous backup. A safety copy of the current database is written to the environment's `backups/` directory first.

```text
Usage: bssh restore [OPTIONS] <FILE>
```

| Flag | Description |
| --- | --- |
| `<FILE>` | Path to the backup file to restore. |
| `-f, --force` | Skip the confirmation prompt. |

### bssh source

Configure inventories that connections can be discovered from. A source remembers how to find hosts (SSH config, Ansible, Tailscale, AWS, GCP). Adding a source does not import anything: run `bssh source sync <NAME>` to reconcile its hosts with the connections database.

```text
Usage: bssh source [OPTIONS] <COMMAND>
```

| Command | Description |
| --- | --- |
| `add` | Register a new inventory source (does not sync it). |
| `list` | List configured sources and their host counts. |
| `sync` | Reconcile a source's hosts with the connection database. |
| `remove` | Remove a source, keeping or deleting its connections. |

### bssh source add

```text
Usage: bssh source add [OPTIONS] <NAME> <KIND>
```

| Flag | Description |
| --- | --- |
| `<NAME>` | Unique name for this source. |
| `<KIND>` | Source kind: `ssh-config`, `ansible`, `tailscale`, `aws` or `gcp`. |
| `--path <FILE>` | Path to the SSH config file (`ssh-config` only). |
| `--inventory <FILE>` | Path to the Ansible inventory file (`ansible` only, required). |
| `--profile <PROFILE>` | AWS profile to use (`aws` only). |
| `--region <REGION>` | AWS region to scan (`aws` only, repeatable or comma-separated). |
| `--address <MODE>` | Address to connect to: `private`/`public`/`dns` for AWS, `internal`/`external` for GCP. |
| `--project <PROJECT>` | GCP project id (`gcp` only, required). |
| `--user <USER>` | Default SSH username for discovered hosts. |
| `--bastion <HOST>` | Bastion/jump host applied to discovered connections. |
| `--bastion-user <USER>` | Username for the bastion host. |
| `--include-offline` | Include offline peers (`tailscale` only). |

## Settings and diagnostics

Change global defaults and check that everything works.

### bssh config

Read or modify `bssh` global defaults. Run with no flags to print current settings; pass one or more flags to update values.

```text
Usage: bssh config [OPTIONS]
```

| Flag | Description |
| --- | --- |
| `--default-user <USER>` | Default SSH username for new connections. |
| `--default-bastion <HOST>` | Default bastion host applied to new connections. |
| `--default-bastion-user <USER>` | Default username for the bastion host. |
| `--default-port <PORT>` | Default SSH port for new connections. |
| `--use-kerberos <BOOL>` | Enable Kerberos authentication by default for new connections. Possible values: `true`, `false`. |
| `--log-level <LEVEL>` | Application log level. Possible values: `trace`, `debug`, `info`, `warn`, `error`, `off`. |
| `--clear-bastion` | Remove the default bastion so new connections are direct. |
| `--search-mode <MODE>` | Connection search algorithm: `bayesian` (usage-ranked) or `fuzzy` (substring). |
| `--recording <STATE>` | Enable or disable session output recording (`on` or `off`). |
| `--recording-tags <TAGS>` | Record only connections carrying these comma-separated tags (empty string clears). |
| `--prediction <STATE>` | Enable or disable context-aware predictive ranking (`on` or `off`). |
| `--capture-cwd <STATE>` | Enable or disable capturing working directory and git root (`on` or `off`). |

Settings that have no flag here are stored in the environment's `config.json`; see [Configuration reference](/reference/configuration/).

### bssh doctor

## Teams

Share connections with your team through an end-to-end encrypted vault. The sync server stores only ciphertext. Team connections appear in `bssh list` and `bssh connect` like any other host. Connecting to one is recorded in the team's signed audit log at the next sync. Your device keys are protected by a passphrase, prompted or read from `BSSH_TEAMS_PASSPHRASE`.

### bssh teams

```text
Usage: bssh teams [OPTIONS] <COMMAND>
```

| Command | Description |
| --- | --- |
| `init` | Set up this machine: create your account and this device's keys. |
| `whoami` | Show this machine's account, device and fingerprint. |
| `create` | Create a team; you become its admin. Use `--org` to choose its organization. |
| `list` | List the teams on this machine. |
| `invite` | Invite someone by email (admin). |
| `uninvite` | Revoke a pending invite (admin): its token stops working and its seat is free again. |
| `join` | Join a team with an invite token and the admin's device fingerprint. |
| `grant` | Give the team key to a waiting device (admin); lists them without `--fingerprint`. |
| `sync` | Sync a team, or every team. |
| `share` | Share a saved connection with a team (or push your edits to a team connection). |
| `unshare` | Delete a team connection for everyone in the team. |
| `members` | List a team's members and their devices. |
| `billing` | Show the plan and seats of a team's organization; subscribe or manage the subscription (organization owner). |
| `remove` | Remove a member and rotate the team key (admin). |
| `audit` | Show and verify the team's audit log (admin). Exits non-zero if anything fails to verify. |

## Organizations

An organization owns teams and, on servers with billing, their subscription and seats. Seats are counted per organization: someone in several of its teams takes one seat, and a pending invite holds one. An organization has no name on the server; it is shown by its owners' emails. See [Organizations](/teams/organizations/).

### bssh org

```text
Usage: bssh org [OPTIONS] <COMMAND>
```

| Command | Description |
| --- | --- |
| `list` | List the organizations you can see. |
| `show` | Show an organization's owners, teams and seats. |
| `create` | Create an empty organization; one is free per account. |
| `owners` | Manage an organization's owners (owner). |
| `billing` | Show an organization's plan and seats; subscribe or manage the subscription (owner). |
