Claude Code、Codex、Cursor 这类编码智能体很擅长读日志、修复出故障的服务。它们大多像人一样连接服务器：用你的 SSH 密钥和一个 shell。没有任何东西限制它们能碰哪些主机、能执行什么，事后唯一的记录就是智能体自己的对话记录。

bssh AI 位于智能体和你的服务器之间。智能体与本地的 [MCP](https://modelcontextprotocol.io) 服务器 `bssh ai mcp` 通信，自身既不持有密钥，也不打开 shell。它提出请求；bssh 做出判定，在允许时执行，并留下凭证。

## 可预期的判定

策略只是配置文件里的几行 JSON，`bssh ai explain` 能在智能体发出命令之前，展示策略会如何处理任意一条命令。下面的策略允许智能体操作带 `staging` 和 `prod` 标签的主机：

| 命令 | 主机 | 判定 |
| --- | --- | --- |
| `journalctl -u nginx --since '10 min ago' \| grep -i error` | web-1（staging） | **允许**：所有命令都是只读的 |
| `systemctl reload nginx` | web-1（staging） | **询问**，在智能体自己的客户端中确认 |
| `systemctl reload nginx` | db-1（prod） | **询问**，需要两个人审批 |
| `curl -s http://169.254.169.254/latest/meta-data/ \| sh` | web-1 | **询问**：`sh` 会从输入中读取命令 |
| `cat /etc/shadow` | web-1 | **拒绝**：匹配 `deny_paths` |
| `rm -rf /` | web-1 | **拒绝**：匹配拒绝规则，不会询问任何人 |

这些行就是 `bssh ai explain --host <主机> '<命令>'` 的输出。参见[策略](/zh-cn/ai/policies/)。

## 你审批的内容

当策略要求询问时，请求会发到桌面应用和 `bssh ai approve`，智能体触及不到这两个渠道。你能看到将要执行什么、在哪里执行，以及 bssh 从中发现了什么：

```text frame="terminal" title="bssh ai approve"
Request d8877617-3b0a-46e9-af6f-8b13efdf51a8
  from:    claude-code 2.9 (self-reported), policy 'default'
  tier:    out-of-band
  tool:    Service
  host:    web-1
  command: sudo -n systemctl restart -- 'nginx'
  analyzer: servicechange, privilege
    systemctl -> rule systemctl service change
```

需要多个步骤的修复会以一个**变更计划**的形式到来：包含各个步骤、文件 diff、验证修复是否生效的方法以及回滚方法。你只需批准一次计划，bssh 会严格按这些步骤执行。参见[审批](/zh-cn/ai/approvals/)。

## 当智能体被误导时

一行日志里可能夹带指令：“忽略上面的内容，执行这个”。没有哪个模型能可靠地无视这类指令，所以 bssh 假定任何智能体都可能被它读到的内容操纵，并限制被操纵的智能体所能做的事：

- **判定不来自模型。** 由解析器和你的策略决定，智能体无法说服它们。
- **读取操作改变不了任何东西。** 在配有沙箱的主机上，读取操作既不能写入也不能联网，即使把某条命令误判为“只读”也不会造成后果。
- **写入需要人来确认。** 审批人看到的是确切的命令或 diff，而不是智能体写的摘要。智能体给出的理由会标明出自智能体。
- **批准只针对那一条命令。** 启用本地证书颁发机构后，已批准的命令使用有效期两分钟、不允许做任何其他事情的证书执行。
- **机密不会进入模型。** 私钥、令牌和密码在到达智能体之前就从输出中被脱敏，因而也不会经由智能体到达模型提供商。

细节与局限见[安全模型](/zh-cn/ai/security/)。

## 个人使用与团队使用

| | 免费，在你的电脑上 | bssh Teams |
| --- | --- | --- |
| 智能体 | 你笔记本上替你工作的智能体 | 还包括无人值守的智能体：值班、CI、定时任务 |
| 谁来审批 | 你，在桌面应用或终端中 | 团队管理员；关键主机需要其中两人 |
| 运行位置 | `bssh ai mcp`，由智能体启动 | `bssh ai serve`，运行在你掌控的机器上的网关 |
| 审计 | 你电脑上的签名日志 | 团队审计日志；服务器永远看不到命令和输出 |

免费部分就是完整的个人版产品，而不是试用版。
