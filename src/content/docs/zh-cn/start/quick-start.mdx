使用 Bayesian SSH，在两分钟内完成你的首次服务器连接。

## 从零开始完成连接

<Steps>
1. ### 保存主机

   使用 `bssh add` 向本地数据库添加一条连接记录。提供一个便于记忆的名称以及目标主机名或 IP 地址：

   ```sh
   bssh add web-prod web-prod.example.com -u deploy --tags prod,web
   ```

   你还可以选择指定端口（`-p 2222`）、SSH 密钥（`-i ~/.ssh/id_ed25519`）或跳板机（`-b bastion.example.com`）。

2. ### 使用模糊匹配连接

   使用 `bssh connect` 连接到已保存的主机：

   ```sh
   bssh connect prod
   ```

   你无需输入完整或精确的主机名称。`bssh` 支持匹配名称、别名、主机名或标签的一部分。连接名中的分隔符会被自动忽略，因此 `webprod` 即可命中 `web-prod`。当命中多台主机时，贝叶斯排序算法会根据你的使用频率和最近连接时间，将最可能的主机排在首位。

3. ### 导入已有 SSH 配置

   如果你已经在 OpenSSH 配置文件中配置过主机，可以直接导入 Bayesian SSH：

   ```sh
   bssh import
   ```

   `bssh import` 默认读取 `~/.ssh/config` 文件。它会自动解析 `Host`、`HostName`、`User`、`Port` 与 `IdentityFile` 指令（跳过 `Match` 块），并批量创建对应的连接。

4. ### 打开桌面应用

   在后台启动图形化桌面应用：

   ```sh
   bssh desktop
   ```

   桌面应用与命令行工具共用同一个本地数据库。你可以在界面中浏览主机列表、按标签筛选、打开内置终端标签页、传输文件，并使用 <kbd>Ctrl</kbd>+<kbd>K</kbd> 呼出命令面板。
</Steps>
